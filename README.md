# personal-website

live at https://apalicepark.github.io/personal-website/


## build

plain HTML/CSS with a little JavaScript

design inspired wiss-style print resumes

## files

- `index.html` home page: bio, education, skills, links
- `experience.html` & `projects.html` one page each
- `style.css` layout & styling
- `script.js` fades sections in as you scroll & runs the project filters

## Running it locally

```bash
git clone https://github.com/apalicepark/personal-website.git
cd personal-website
python3 -m http.server
```

then, open http://localhost:8000
